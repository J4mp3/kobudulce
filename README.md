# Kobu Dulce · Menú online

Menú y página de pedidos de **Kobu Dulce**, repostería artesanal en Ingeniero Maschwitz, Buenos Aires.

Budines, brownies, lemonies, kobulitos y skoncitos hechos en casa. Los clientes arman su pedido en la página y lo envían directo por WhatsApp.

## Qué tiene la página

- Menú por categorías con precios, opciones (cobertura, glasé, sabores) y productos agotados o nuevos.
- Pedido armado con número, fecha de entrega, franja horaria, forma de pago y dedicatoria, enviado por WhatsApp.
- Aviso en vivo del horario de corte de pedidos.
- Página para negocios con pedido de lista mayorista.
- Reseñas de clientes, preguntas frecuentes, términos y condiciones, privacidad y cookies.
- Se puede instalar en el celular como app.

## Archivos

| Archivo | Qué es |
|---|---|
| `index.html` | Menú (página principal) |
| `negocios.html` | Página para negocios |
| `datos.js` | Productos, precios, opciones, reseñas y configuración |
| `fonts/` | Tipografías |
| `manifest.webmanifest`, `icon-*.png` | Ícono y datos para instalar como app |

## Actualizar precios y productos

Todo lo que cambia seguido está en `datos.js`. Para actualizar la página, se reemplaza ese archivo en el repositorio y GitHub Pages publica el cambio en uno o dos minutos.
